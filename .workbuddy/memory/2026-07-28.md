## 中间区域方案决策
- 讨论是否把中间改成 Codex/WorkBuddy 式原生聊天气泡 UI
- 给出三条路线：A(解析JSONL历史回放,只读) / A+(回放+输入框走CLI) / B(直连API自建客户端)

- `Sidebar.tsx`：props 加 runningSessions；getAgentIcon 加 isRunning 参数，运行中渲染带 .running class 的圆点 + CSS 变量 --agent-color
- `Sidebar.css`：新增 .agent-color-dot 基础样式 + .running::before 脉冲光环动画(agent-pulse keyframes, scale 1→2.6 + opacity 0.7→0, 1.4s)，带 prefers-reduced-motion 兜底
- 校验：tsc --noEmit 通过，cargo check 通过(14.88s)
- 用户后续调整：停止的会话不显示圆点(透明占位 .idle)，只运行中显示呼吸闪烁(.running + agent-blink)
- 用户再升级为三态：进程退出→消失 / 进程在+空闲→常亮 / 进程在+输出中→快闪(0.5s)。前端 debounce terminal-output 事件(Rust payload 加 session_id)800ms 切 idle。App.tsx 加 outputtingSessions+outputTimers+terminal-output 监听。CSS .running 常亮、.running.outputting 快闪。tsc+cargo check 通过
- 会话列表折叠：5天内全显，5天外折叠"显示更多(剩余N条)"，每次加载10条(OLDER_PAGE_SIZE)。搜索时不折叠。纯前端 Sidebar.tsx(RECENT_THRESHOLD_MS/OLDER_PAGE_SIZE 常量+olderCounts state+isRecent+IIFE 折叠渲染)+Sidebar.css(.load-more)。后端 get_sessions 无需改。tsc 通过
- 项目列表限制：非搜索时只显示最近打开的10个项目(MAX_VISIBLE_PROJECTS，projectGroups.slice(0,10))，搜索时不限制。Sidebar.tsx 加常量+改 visibleGroups。tsc 通过
- 调研：Claude Code 原生会话清理机制——本地 transcript(~/.claude/projects/xxx.jsonl)默认30天自动删除，可用 cleanupPeriodDays 调；无原生删除单个会话命令(会话选择器只能恢复/重命名/分支)；/clear 只清上下文不删文件。MiMo/Kimi 无文档提及自动清理。结论：agent-hub 加硬删除仍有价值(原生无此能力)，但用户暂未决定是否做
