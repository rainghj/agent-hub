- 用户要求重新设计 Agent Hub 界面（Tauri 桌面应用，三栏布局），原版视觉粗糙
- 在 Ardot 画布上完成了完整重设计稿（fileId: 708727839368202）
- 设计风格：Dark First Pro + Linear 紫 #7C3AED 强调色，Inter + JetBrains Mono 字体
- 三栏结构：左侧项目列表(260px) / 中间会话列表主视图 / 右侧文件浏览器(280px)

- 卡片含三种交互状态示意：selected (紫边+指示条) / hover (灰边高亮) / default (微妙边框)
- Ardot 技术笔记：
  - primaryAxisAlignItems 用 MIN/MAX/CENTER/SPACE_BETWEEN 等，不用 START/END
  - counterAxisAlignItems 用 MIN/MAX/CENTER/BASELINE，不用 STRETCH
  - stroke color 不支持 a (alpha) 通道，用 {r,g,b} 即可
  - fillOpacity 属性可能不被 frame 支持，改用深色 hex 近似透明效果

## 中间区域方案决策
- 讨论是否把中间改成 Codex/WorkBuddy 式原生聊天气泡 UI
- 给出三条路线：A(解析JSONL历史回放,只读) / A+(回放+输入框走CLI) / B(直连API自建客户端)
- **用户最终决策：中间保留现有 xterm.js 终端，不改成聊天 UI**
- 理由：agent-hub 定位是统一管理 CLI agent 会话，CLI 完整能力(工具调用/流式/交互确认)都在终端里；改成气泡 UI 会丢能力，走 API 成本高
- 剩余可做项：左侧会话列表加"运行中"动态状态图标(需 Rust 端 PTY 进程状态跟踪 + 前端 Sidebar 联动)

## 实现：运行中会话动态图标（已完成）
- Rust 端 `terminal.rs`：`spawn_reader_thread` 新增 agent/session_id 参数；PTY 子进程退出(reader EOF/Err)时 emit `terminal-status` 事件，payload 含 terminal_id/agent/session_id/status=exited；spawn_terminal 传 Some(agent/session_id)，spawn_shell 传 None
- 前端 `App.tsx`：新增 `runningSessions: Set<string>` 状态；openSessionTab 新建时加入；doCloseTab 关闭 session tab 时移除；新增 useEffect 监听 `terminal-status` exited 事件移除对应 session；传 runningSessions 给 Sidebar
- `Sidebar.tsx`：props 加 runningSessions；getAgentIcon 加 isRunning 参数，运行中渲染带 .running class 的圆点 + CSS 变量 --agent-color
- `Sidebar.css`：新增 .agent-color-dot 基础样式 + .running::before 脉冲光环动画(agent-pulse keyframes, scale 1→2.6 + opacity 0.7→0, 1.4s)，带 prefers-reduced-motion 兜底
- 校验：tsc --noEmit 通过，cargo check 通过(14.88s)
- 数据流：打开会话→spawn PTY→running / 进程退出→EOF→terminal-status事件→移除running / 关tab→移除running
- 用户后续调整：停止的会话不显示圆点(透明占位 .idle 保持标题对齐)，只运行中显示呼吸闪烁圆点(.running + agent-blink keyframes, opacity 0.35→1 + scale 0.85→1.1, 1.2s)，去掉了扩散光环
- 用户再升级为三态：进程退出→消失 / 进程在+空闲→常亮 / 进程在+输出中→快闪(0.5s)。判断"是否在输出"用前端 debounce：terminal-output 事件(Rust 端 payload 加 session_id 字段)收到即 outputting，800ms 无新输出切回 idle。App.tsx 新增 outputtingSessions + outputTimers(ref) + terminal-output 监听；terminal-status exited 与 doCloseTab 同步清理 outputtingSessions 及 timer。CSS .running 常亮、.running.outputting 快闪。tsc + cargo check 通过
